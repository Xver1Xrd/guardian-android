# Guardian 0.1 preview — тестовая сборка

Это ранняя локальная версия для проверки с синтетическими данными. **Не храните в ней реальные пароли.** Независимого аудита и проверенного способа восстановления данных пока нет.

## Доступно

- Создание локального хранилища с мастер-паролем, Argon2id, случайным DEK и AES-256-GCM.
- Зашифрованные логины и заметки, поиск, редактирование, корзина и восстановление.
- Генератор случайных паролей, ручной ввод `otpauth://totp` и отображение TOTP.
- Блокировка при уходе приложения в фон; локальный режим без разрешения `INTERNET`.

## Ограничения

Нет резервного копирования и восстановления, биометрии, Autofill, Credential Provider, passkeys, QR-сканирования, синхронизации и полноценного тестирования на физическом устройстве. Подробности: [план работ](ROADMAP.md) и [проверка безопасности](SECURITY_REVIEW.md).

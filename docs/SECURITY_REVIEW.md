# Текущая проверка безопасности, 2026-11-06

Это внутренняя проверка раннего этапа, не независимый аудит и не подтверждение соответствия OWASP MASVS.

## Подтверждено

- `VaultCryptoTest` и `VaultCodecTest` проверяют неверный мастер-пароль, подмену AAD/шифртекста, смену мастер-пароля, повреждённый бинарный ввод и вектор Argon2id из RFC 9106 §5.3. Всего 5 тестов, ошибок нет.
- `PasswordGeneratorTest` проверяет ограничения символов и отсутствие совпадений в 100 тестовых результатах. Это не статистическое доказательство качества RNG.
- В собранном debug APK: `allowBackup=false`, `fullBackupContent=false`, cleartext traffic запрещён; разрешения `INTERNET` нет. Файлы помещаются в `noBackupFilesDir`.
- Чувствительный экран использует `FLAG_SECURE`, ключ в `VaultKey` обнуляется при блокировке. Android Lint: 0 ошибок, 1 предупреждение о target SDK 36 при compile SDK 37.2.
- Проверка `BidiSpoofing` в Android Lint зависает в Kotlin PSI на этой конфигурации. Временно отключена только она; CI выполняет отдельный прямой поиск управляющих символов в исходниках через `scripts/check_bidi.py`.

## Не подтверждено

- Нет независимого криптографического аудита и проверки всех транзитивных зависимостей на CVE.
- Нет воспроизводимых тестов на реальном устройстве, сканирования утечек памяти, проверки восстановления из резервной копии и отказов хранилища при заполненном диске.
- Открытый заголовок файла раскрывает тип записи (`note`/`login`); названия, логины и URL зашифрованы. Нет аутентифицированного индекса всех записей: удаление или откат целого файла может остаться незамеченным.
- В списке логинов хранятся только заголовки, логин и URL. Для построения списка сейчас расшифровывается полная запись, но пароль и TOTP URI не удерживаются в модели списка; при открытии запись читается заново. Тела заметок пока держатся в памяти до блокировки, а ART/JVM не гарантирует уничтожение копий строк. Изменяемый буфер декодированного TOTP секрета обнуляется при закрытии конфигурации.
- TOTP URI хранится вместе с паролем в одном шифрованном хранилище; пользователь предупреждён о совместном риске. Нет защиты от root/скомпрометированной ОС, нет биометрии, Autofill, Credential Provider, passkeys, синхронизации и проверки их моделей угроз.

До закрытия этих пунктов хранить реальные секреты в приложении нельзя.

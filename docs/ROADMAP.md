# Состояние разработки

- [x] Исследованы официальные страницы Android Credential Provider, Autofill, OWASP MASVS и версии базовых зависимостей.
- [x] Первоначальная модель угроз и формат с версией.
- [x] Криптографический модуль: Argon2id, случайный DEK, AES-GCM, AAD, смена мастер-пароля, бинарный формат.
- [x] JVM тесты, включая вектор RFC 9106.
- [x] Android APK: локальные защищённые логины и заметки, поиск, блокировка, корзина, атомарная запись.
- [x] Установка и запуск на эмуляторе Android 36, инструментальный тест локального хранилища на синтетических данных.
- [ ] Проверка на реальном телефоне и автоматические Compose UI тесты.
- [ ] Калибровка KDF, безопасная смена пароля в UI, recovery key, резервные копии и проверка восстановления.
- [ ] Аутентифицированный индекс, миграции, защита от потери и отката файлов, 10 000 записей.
- [ ] Карты, документы и другие типы; расширенный поиск, фильтры, папки, история логинов.
- [x] Генератор случайных паролей с настройкой длины, символов и исключений.
- [x] TOTP: ядро с векторами RFC 6238, ручной импорт `otpauth://totp`, зашифрованное хранение вместе с логином, код и таймер.
- [ ] QR-сканирование, копирование кодов с защитой буфера, словарные фразы, оценка стойкости, биометрия, импорт/экспорт.
- [ ] Autofill и Credential Provider с проверкой происхождения.
- [ ] Passkeys только после совместимой реализации и проверки.
- [ ] Опциональная синхронизация после стабильной локальной версии.
- [ ] Динамические проверки, аудит зависимостей и независимый аудит безопасности.
